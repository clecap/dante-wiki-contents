This is a test for the preamble features of Parsifal.

The <code>&lt;preamble&gt;</code> tag defines Latex abbreviations and macros which are applied to all following Latex sections. Multiple tags overwrite each other.
<preamble>
\def\Alice{Alice}
</preamble>

== Usage 1 ==
<amsmath>
This here is \Alice
</amsmath>

== Usage 2 ==
<amsmath>
And this here also is \Alice again.
</amsmath>
